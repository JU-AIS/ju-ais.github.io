# JU AIS website

Static site for Jönköping University AI Student Association. Astro, vanilla TypeScript, CSS. Deployed to GitHub Pages.

## Run

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

## Where things live

| What | Where |
|---|---|
| Name, Join/Discord links, emails | `src/config.ts` |
| Colors and fonts | `src/styles/theme.css` |
| Logo | `public/logo.svg` (light bg), `public/logo-dark.svg` (dark bg), `public/favicon.svg` + PNGs rendered from it (`favicon-96.png`, `apple-touch-icon.png`, for Safari) |
| HiTract club (event source) | `hitractClub` in `src/config.ts` |
| Synced events (generated, not committed) | `src/content/events/hitract/` |

## Events

Events come only from HiTract. `scripts/sync-hitract.ts` fetches all the club's events (upcoming and past) and writes them to `src/content/events/hitract/`, which is gitignored. The Deploy workflow runs it before every build: on each push to `main`, nightly (01:00 UTC) and on demand. The nightly run also moves finished events to "Past events". If HiTract is down, the deploy fails and the last published site stays live. An event deleted in HiTract disappears from the site on the next deploy.

- Run the sync now: Actions → Deploy → Run workflow.
- Run it locally: `npm run sync:events` (before `npm run dev` to see events).

Each event links directly to its modal at `/#<slug>` and `/events#<slug>`.

## Test

```sh
npm test           # unit tests (Vitest)
npm run test:e2e   # end-to-end tests (Playwright)
npm run check      # build + all tests
```

## SBOM

Each deploy publishes a CycloneDX SBOM of the build at https://ju-ais.github.io/sbom.cdx.json (generated by `npm run sbom`, not committed). Run `npm run --silent sbom > /tmp/sbom.cdx.json` to generate one locally (outside the repo).

## Deploy

`main` is protected: changes go through a pull request, and the CI workflow (`test`) must pass before merging. Merging deploys the site. Requires repo Settings → Pages → Source: GitHub Actions.

## Maintenance

| What | Why |
|---|---|
| Scheduled workflows stop after 60 days without repo activity | GitHub disables them in public repos (e.g. over the summer). The nightly sync and rebuild then stop until someone re-enables the workflow in the Actions tab or runs it manually. |
| Keep the repo name `ju-ais.github.io` | It serves the site at the root URL. Renaming moves it to `/<repo>/` and needs an Astro `base` change. With a custom domain the name no longer matters. |
